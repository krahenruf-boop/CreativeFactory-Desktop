# Creative Factory 飞书接单 V1

同事使用飞书和夸克，个人 Mac 下载素材、执行已有剪辑流程、回传成片。
仅收到任务编号才算受理成功。电脑需要联网、唤醒并登录桌面；本版没有离线云端接单服务。

## 一次性配置

1. 飞书独立企业自建应用：开启机器人能力，应用身份最小收发权限
   `im:message.group_at_msg:readonly`、`im:message:send_as_bot`。
   首次创建专用群另需 `im:chat:create`、`im:chat:read`；不申请通讯录或读取所有群消息。
2. 事件与回调分别启用长连接：事件 `im.message.receive_v1`，回调 `card.action.trigger`。
   两项都需要配置；只看到 WebSocket 连接成功并不能证明卡片回调可用。
3. 正常发布应用，由企业管理员完成需要的审批。不要改变已有文案库或 MCP 应用。
4. 本机网页 → 设置 → 飞书接单：保存独立凭据、连接机器人、生成十分钟绑定码。
   在新专用群里由管理员 @机器人发送 `绑定 <绑定码>`。绑定后只能服务这个群。
5. 使用夸克官方 Skill 安装并授权当前执行账号。不要从桌面客户端提取 Cookie。
   官方工具位置：`~/.agents/skills/quarkclouddrive/scripts/quark-drive.cjs`。
6. 验收前正式接单关闭；仅管理员可提交三条视频测试。
   完成飞书口播确认、标题确认、三条真实成片与夸克交付后，由管理员打开成片链接并点击“确认三条成片交付”。
   验收通过后可在本机设置开启正式接单，不因上传完成自动开放。

可用 `python3 scripts/setup_feishu_tasks.py --prepare` 准备可选 SDK 和专用凭据工具。
它不构建 App、不修改原有 Provider 钥匙串。依赖版本锁定于 `manifests/dependencies-feishu.json`。

## 使用

- `@机器人 新建任务`：填写产品、市场、模式、素材数量、夸克文件夹链接和提取码；预设选择暂时隐藏，内部使用通用素材分析。
  默认巴西（pt-BR）、搬运模式、10 条素材；市场和数量可手动修改。`新建测试任务`及首次验收任务仍默认 3 条。
- 视频直接放在分享文件夹内，不嵌套子文件夹。素材按文件名自然排序，下载后校验大小、哈希及视频流。
- 可以粘贴夸克整段分享文案，自动提取唯一有效链接及提取码。受理后原表单变成任务状态卡；重复点击返回原任务，不重复创建或改写素材链接。
- 口播卡片每页最多三条，可替换口播，所有内容准备好后批量确认。
  飞书单个输入框最多 1000 字符，口播替换和任务要求遵循这一平台限制；已有口播展示不截断。
  所有输入框与下拉框铺满卡片。修改、报错、保存和返回均在同一确认卡内更新；支持“保存并修改下一条”。失败保留输入，保存成功的重复点击不重复请求文案处理。
- 每条视频的标题下直接显示“选用标题 1 / 2 / 3”按钮，点击即保存并标明已选项；可重生、自行填写。
  每页最多三条，翻页保留选择，最后点击“确认全部标题并开始剪辑”。缺少中文对照时先补齐翻译，不重写已展示的标题。
- 只有负责人和管理员可操作。旧卡片、重复事件、重复确认不能重复推进任务。
- `@机器人 查询 CF-任务编号`：更新任务状态。
- 出错时在卡片中补交素材、重试未完成项或重试上传。已成功成片与已完成配音不重复执行。

只有独立状态卡更新进度，每个阶段即时更新，同阶段最多每三十秒更新。
阶段确认、异常和完成在对应卡片内 @负责人，不再为每次修改或错误追加“任务需要关注”消息。
完成时会在群底部另发完整交付卡，包含成片链接、提取码和验收按钮，避免按钮埋在最初的任务消息中。
同一交付不会因为重启或重复查询再次发送；确认后同步更新交付卡。
夸克工具返回的非空官方提示会原样保留并展示在任务状态中，成功返回的提示也不会遗漏。

## 数据与安全边界

- 素材：`~/Movies/Creative Factory/Media/Feishu/<任务编号>/`。
  补交后的素材使用新的 `-R<n>` 目录，避免覆盖已经下载的文件。
- 成片：对应本地素材目录下 `outputs/`，不写到 App 内。
- 夸克转存：`/Creative Factory/接单/<任务编号>/`；成片：`/Creative Factory/成片/<任务编号>/`。
  只分享当前成片子目录，默认提取码保护、七天有效。
- 接入记录：`~/Library/Application Support/AutoCut/integrations/feishu_tasks/`，独立 SQLite。
  不迁移、不改变已有任务数据库结构。不自动删除素材、缓存或成片。
- 机器人凭据：钥匙串服务 `com.autocut.feishu-tasks`，不回显；夸克授权由官方工具保存。
- 本机配置接口继续使用原有本地会话和 Origin 校验；不公开开发网页、回调端口或文件浏览接口。
- 已完成状态不会因为之后移动成片而回退为失败；上传失败是独立状态，只重试上传。
